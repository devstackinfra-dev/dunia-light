# 🎬 Dúnia Light — Showcase Cinematográfico 35mm & Alta Gastronomia

Landing page imersiva de alta conversão desenvolvida para o **Espaço Dúnia**, combinando estética editorial de luxo com uma galeria **3D interativa em película 35mm (curva S contínua sem emendas)**, apresentação de espaços/gastronomia e integração direta com Google Maps na seção de Localização Nobre.

- **Repositório:** `https://github.com/devstackinfra-dev/dunia-light`
- **Stack:** Next.js 14/15 (App Router) · TypeScript · Tailwind CSS · Three.js / WebGL / CSS 3D Reel · Lucide Icons

---

## ✨ Destaques Técnicos

- **Carretel Cinematográfico 35mm em Curva S:** Renderização fluida de 4 trilhas de película fotográfica com encaixe subpixel, perfurações Kodak 35mm realistas e iluminação de estúdio.
- **Hero Editorial Minimalista:** Foco em autoridade visual e CTA direto de orçamento/agendamento.
- **Card de Localização Nobre:** Integração direta com rota Google Maps e informações executivas para eventos corporativos e sociais.
- **Performance Otimizada:** Versão enxuta (`dunia-light`) projetada para carregamento instantâneo em dispositivos móveis de alto padrão.

---

```bash
npm install
npm run dev
```
